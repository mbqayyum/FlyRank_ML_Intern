## 3. Typography Choice

We use a disciplined **two-font system** (Google Fonts, free & open source):

| Role | Font Family | Weights / Styles | Application & Rules |
|---|---|---|---|
| **Headings & Brand Title** | **`Outfit`** | SemiBold (600), Bold (700) | Hero headlines, section titles, table headers, and primary navigation. Geometric, modern, crisp. |
| **Body, Data & Code** | **`Inter`** / **`JetBrains Mono`** | Regular (400), Medium (500), Monospace | Narrative copy, data tables, metrics cards, code blocks, and feature names. Maximum legibility across screen sizes. |

> [!TIP]
> **Typography Rule:** Never use more than two font families across the portfolio. Headings use `Outfit` with tight tracking (`-0.02em`) for authority; body text uses `Inter` with comfortable line-height (`1.6`) for rapid scanning in under 30 seconds.

## 4. Color Palette & Hex Codes

The palette is kept deliberately tight (4 colors total) to maintain a calm, high-contrast, professional technical tone:

```
┌─────────────────────────────────────────────────────────────────────────┐
│                                                                         │
│   #F8FAFC            #0F172A            #1E293B            #0EA5E9      │
│  [ Canvas ]         [  Text  ]        [ Surface ]        [ Accent ]     │
│  Near-White        Near-Black         Dark Slate         Teal Cyan      │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

| Token | Hex Code | Color Name | Role & Application |
|---|---|---|---|
| **Canvas Background** | **`#F8FAFC`** | Slate 50 (Near-White) | Clean, distraction-free page background canvas. High readability. |
| **Primary Text** | **`#0F172A`** | Slate 900 (Near-Black) | High-contrast, non-fatiguing body text and primary headings. |
| **Dark Surface** | **`#1E293B`** | Slate 800 (Deep Slate) | Container cards, header bar background, metric cards, and table headers. |
| **Single Accent** | **`#0EA5E9`** | Sky 500 (Teal-Cyan) | Key metrics (`3.1x Precision Lift`), primary CTAs, signal nodes, and active states. |
| *Muted Border* | `#E2E8F0` | Slate 200 (Neutral) | Subtle grid lines, card borders, and table row dividers. |

> [!NOTE]
> **Palette Philosophy:** `#0EA5E9` is the *only* accent color permitted. It highlights the single primary conversion action (booking a 15-minute discovery call) and key ML metrics, ensuring the work is the loudest thing on the page.
